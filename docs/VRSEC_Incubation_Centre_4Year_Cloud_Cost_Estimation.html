1 Executive Summary

A rigorous, evidence-based infrastructure and financial estimation was conducted for operating the VRSEC Incubation Centre Management System across a four-year planning horizon (2026-2030) for a target population of approximately 1,400 registered members (students, staff, faculty, and administrators). The application is an enterprise-grade React 19 / Vite single-page application engineered with an offline-first architecture, backed by Supabase PostgreSQL and Cloudflare Pages/R2.

  • Database Storage: All 24 PostgreSQL tables combined will consume approximately 66.6 MB in Year 1 and 247.9 MB cumulative after four full academic years (653,730 total rows in Expected Usage). This fits comfortably within both the Supabase Free limit (500 MB, 49.6% consumed) and the Supabase Pro tier (8,192 MB, only 3.0% consumed).
  • Cloudflare R2 Object Storage: Four-year cumulative file storage across student avatars, component shelf photos, project showcases, event photos, research papers, and rolling disaster-recovery backups is 1.68 GB (3,321 files). Because Cloudflare R2 provides a permanent 10 GB free monthly allowance with $0 data egress fees, file storage is 100% FREE ($0.00/year).
  • Cloudflare Pages Hosting & Functions: Static SPA asset hosting, global CDN edge caching, and serverless Pages Functions execute completely within Cloudflare Pages Free Tier (unlimited bandwidth, 100,000 free function requests/day). Hosting cost is $0.00/year.
  • Authentication MAU: Supabase Free and Pro tiers both include 50,000 Monthly Active Users (MAU). With 1,400 total registered members, peak active monthly users will never exceed 1,400 (only 2.8% of the free allowance). Auth charges are $0.00/year.
  • Recommended Institutional Plan: Supabase Pro at $25.00/month ($300.00/year + 18% Indian GST = Rs. 30,090/year or Rs. 2,508/month). This eliminates the Supabase Free tier 7-day project inactivity pause during vacations and provides automated daily backups with a 24/7 SLA.
  • Unit Economics: The total cost per registered student is just Rs. 21.49 / year (Rs. 85.97 for all four academic years combined, or less than $1.02 USD total).
Executive Verdict: Exceptional Cost Efficiency & Zero Expensive Server Upgrades The local-first architecture and Cloudflare zero-egress R2 integration allow the entire college incubation laboratory to operate for four full years on a total infrastructure budget of Rs. 1,20,360 ($1,416 USD including 18% GST). No expensive server upgrades are required.

2 Existing Architecture Assessment

The application architecture comprises three tightly decoupled tiers designed for high resilience, offline autonomy, and low cloud bandwidth:

  • Client Layer (React 19 + Vite): Single-page application utilizing memoryStore for synchronous sub-millisecond in-memory state and dual-persistence (localStorage + IndexedDB). Reads are satisfied locally; only mutations and initial sync pulls hit the cloud.
  • Storage & Sync Layer (SyncService): Implements an exponential backoff mutation queue and atomic RPC idempotency. Mutations generated offline are queued and replayed automatically upon network reconnection.
  • Database Layer (Supabase PostgreSQL): 24 relational tables, 17 RPCs/triggers, and strict Row Level Security (RLS) policies. Migration 007 isolates student profiles and staff desks; Migration 008 standardizes the 7-category inventory taxonomy.
  • Edge & Object Tier (Cloudflare Pages + R2): Static frontend served via Cloudflare global edge CDN. Serverless functions proxy authenticated image uploads to private Cloudflare R2 bucket (CMS_BUCKET).
